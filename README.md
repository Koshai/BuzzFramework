# Buzz Framework

Buzz Framework is a Blazor component ecosystem with AI-ready patterns, provider abstractions, and sample implementations.

## NuGet Packages (Local Build)

- `Buzz.Framework.Core`
- `Buzz.Framework.Blazor`
- `Buzz.Framework.Provider.OpenAI`
- `Buzz.Framework.Provider.Ollama`

Use `tools/pack-local.ps1` to generate local packages into `.artifacts/nuget`.
