# BuzzSkeleton

`BuzzSkeleton` shows loading placeholders while data or components are still being prepared.

## Basic usage

```razor
<BuzzSkeleton Variant="text" Width="70%" Height="0.9rem" Animated="true" />
```

## Parameters and effects

- `Variant`: `text`, `rect`, `circle`.
- `Width`: CSS width value.
- `Height`: CSS height value.
- `Radius`: border radius for text/rect variants.
- `Animated`: enables shimmer animation.
